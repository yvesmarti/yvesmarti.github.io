Le contexte

Passer d'un usage manuel à une approche dynamique

Dans les projets liés aux données territoriales — entreprises, géographie, open data — l'utilisation d'APIs permet d'automatiser la collecte et d'enrichir les analyses sans passer par des fichiers statiques souvent obsolètes.

Même avec un niveau intermédiaire, il est possible d'intégrer ces APIs dans des workflows simples (Power Query, scripts Python) et d'en tirer une valeur immédiate : référentiels toujours à jour, géocodage en masse et croisement facilité entre plusieurs sources.

Tester les requêtes directement dans le navigateur est le meilleur point de départ : lire la structure JSON, modifier progressivement les paramètres, puis industrialiser dans un outil de traitement.

Les outils

Six APIs publiques pour couvrir tous les besoins territoriaux

1. Géographie administrative

geo.api.gouv.fr
Référentiel officiel des communes, départements et régions
API officielle pour récupérer les codes INSEE, les populations et construire des référentiels territoriails propres. Aucune clé requise.

Exemple : rechercher une commune par nom.

Requête commune HTTP 
https://geo.api.gouv.fr/communes?nom=caen&fields=nom,code,population&format=json

Résultat : nom, code INSEE, population.

Exemple : récupérer les communes d'un département.

Communes par département HTTP 
https://geo.api.gouv.fr/departements/14/communes

Très utile pour faire des jointures territoriales et construire des référentiels propres.

2. Géocodage officiel

api-adresse.data.gouv.fr
Convertir une adresse en coordonnées GPS
Géocodage officiel de la Base Adresse Nationale. Retourne latitude, longitude et score de précision. Idéal pour la cartographie.
Géocodage simple HTTP 
https://api-adresse.data.gouv.fr/search/?q=12 rue de paris caen

Exemple avec filtre sur une commune :

Filtre communal HTTP 
https://api-adresse.data.gouv.fr/search/?q=mairie&city=Caen

Indispensable pour la cartographie et la géolocalisation de fichiers entreprises.

3. Entreprises — API Sirene (INSEE)

api.insee.fr
Données officielles sur les entreprises françaises
SIRET, activité (NAF), adresse et état administratif. Nécessite une clé API gratuite. Parfaite pour les analyses économiques locales.
Établissements actifs par code postal HTTP 
https://api.insee.fr/entreprises/sirene/V3/siret?q=codePostalEtablissement:14000 AND etatAdministratifEtablissement:A&nombre=10

Résultat : SIRET, activité (NAF), adresse complète.

⚠️ Cette API nécessite une clé API gratuite disponible sur api.insee.fr.

4. OpenStreetMap — Overpass API

overpass-api.de
Interroger directement la base OpenStreetMap
Requêteur puissant pour extraire des POI (restaurants, écoles, commerces) dans une zone géographique délimitée.
Restaurants à Caen Overpass QL 
https://overpass-api.de/api/interpreter?data=[out:json];
area[name="Caen"]->.searchArea;
(
  node["amenity"="restaurant"](area.searchArea);
);
out;

Résultat : liste de points géolocalisés prêts à être cartographiés.

5. Géocodage libre — Nominatim

nominatim.openstreetmap.org
Alternative simple et gratuite au géocodage
Service de géocodage basé sur OpenStreetMap. Retourne coordonnées et bounding box. Attention aux limites d'usage en volume.
Recherche Nominatim HTTP 
https://nominatim.openstreetmap.org/search?q=Caen&format=json

6. Données foncières — DVF (Etalab)

app.dvf.etalab.gouv.fr
Transactions immobilières en France
Accès indirect via fichiers ou endpoints Etalab. Permet l'analyse du marché immobilier et le croisement avec d'autres données territoriales.

L'accès se fait principalement via les fichiers open data ou les API Etalab dérivées. Les données DVF permettent d'analyser les prix au m² par commune, de suivre les tendances du marché et d'enrichir les études territoriales.

Mise en pratique

Un workflow combiné pour des bases territoriales complètes

Dans mes projets, je combine souvent plusieurs APIs pour constituer une base de données territoriale directement exploitable dans QGIS ou Power BI.

geo.api.gouv.fr
→
API Sirene
→
api-adresse.data.gouv.fr
→
Overpass API

Le processus en quatre étapes :

  • Récupération des communes via geo.api.gouv.fr pour obtenir les codes INSEE du territoire ;
  • Extraction des entreprises via l'API Sirene en filtrant par code postal et état actif ;
  • Géocodage des adresses via api-adresse.data.gouv.fr pour obtenir latitude et longitude ;
  • Enrichissement cartographique via Overpass pour ajouter des POI pertinents (commerces, services).
Résultat : une base de données territoriale complète, actualisable en un clic, directement exploitable dans QGIS ou Power BI.

Les avantages

Pourquoi utiliser des APIs ?

Les APIs transforment fondamentalement la manière de travailler avec les données publiques :

Automatiser les mises à jour
Plus besoin de retélécharger manuellement des fichiers à chaque changement : l'actualisation se fait en un clic ou par script planifié.
Éviter les fichiers statiques obsolètes
Les données interrogées en direct reflètent l'état actuel du référentiel, sans décalage temporel ni erreur de version.
Croiser facilement plusieurs sources
La jointure entre géographie, entreprises et adresses devient reproductible et programmatique, même sur de gros volumes.
Reproductibilité des analyses
Un workflow documenté en Power Query ou en Python peut être partagé, audité et réutilisé sur d'autres territoires sans effort.

Conclusion

Vers des workflows reproductibles

Les APIs open data permettent de passer d'un usage manuel des données à une approche beaucoup plus dynamique. Même avec un niveau intermédiaire, il est possible de les intégrer dans des workflows simples et d'en tirer beaucoup de valeur.

Leur véritable force réside dans la combinaison : aucune API seule ne répond à tous les besoins, mais assemblées intelligemment, elles constituent une infrastructure de données territoriales puissante et gratuite.

Conseils pratiques pour démarrer :
• Tester les requêtes directement dans le navigateur
• Lire la structure JSON (même sans tout comprendre)
• Modifier progressivement les paramètres
• Documenter chaque étape dans Power Query ou un notebook Python

Prochaine étape : automatiser ces requêtes dans un workflow complet avec Power Query ou Python pour obtenir une actualisation sans intervention manuelle.
