# 🚛 Suivi Collecte Déchets

PWA pour suivi GPS des tournées de collecte.

## 🚀 Déploiement GitHub Pages

1. Créer un repo public sur GitHub
2. Uploader tous les fichiers de ce dossier
3. Settings → Pages → Source: `main` branch → Save
4. Accéder à `https://votre-nom.github.io/nom-du-repo/`

## 📱 Utilisation

1. Ouvrir l'URL sur Android avec Chrome
2. Cliquer "Tester le GPS" et autoriser
3. Démarrer la tournée
4. Signaler les anomalies
5. Exporter en GPX/GeoJSON

## ⚠️ Important

L'app doit être servie en HTTPS (GitHub Pages) pour que le GPS fonctionne sur Android.
En `file://` local, Chrome bloque les permissions GPS.
